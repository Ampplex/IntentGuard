Live run · Razorpay AI Buildathon, Track 01

IntentGuard

The authorization layer that lets a Razorpay merchant safely accept an order from an AI buyer. Every figure below was produced by running the system, not typed in.

01

Five transactions, start to finish

User instruction, mandate, bounded merchant view, negotiation, decision, payment. The merchant never sees the ceiling in any of them.

02

Every hostile mode, judged on arrival

One row per behaviour the merchant service can adopt. The quote crosses the wire as JSON and is parsed before it is judged, so a payload carrying a field the schema has no slot for is part of the test rather than something no fixture could express.

03

Two failures, handled

The track asks to see one failure handled gracefully. These are both of them, run live.

04

The benchmark

The synthetic training slice, scored through the same entry point a merchant's payload uses.

05

The audit trail

Every decision is recorded, blocks included, each chained to the one before it. A record altered afterwards breaks every link downstream.
